## الاصطلاحات

- `REQ-n` مطلب وظيفي · `NFR-n` قيد غير وظيفي · `AC-n.m` معيار قبول
- **P0** يحجب الإطلاق · **P1** مهم · **P2** تحسين
- كل SPEC يُلزَم بذكر: النطاق، ما هو خارج النطاق، معايير القبول، المخاطر، وأثره على نسخة البيانات.
