# القاموس التقني — نسخة Angular

مرجع شخصي شجري قابل للبحث بالنص والصوت، مبني على Angular 18 (standalone components + signals).

## التشغيل

```bash
cd angular-app
npm install
npm start
```

يفتح على `http://localhost:4200`.

> **مهم بخصوص الميكروفون:** المتصفح لا يحفظ إذن الميكروفون إلا على أصل آمن
> (`https` أو `http://localhost`). التشغيل عبر `npm start` يوفّر ذلك، فيُطلب الإذن
> **مرة واحدة فقط** ثم يُحفظ. فتح ملف HTML مباشرة (`file://`) يجعل المتصفح يسأل في كل مرة —
> وهذا قيد أمني في المتصفح لا يمكن تجاوزه برمجياً.

## البناء للنشر

```bash
npm run build
```

الناتج في `dist/dev-dictionary/browser` — ارفعه على أي استضافة ثابتة (Vercel / Netlify / GitHub Pages).

## الوثائق

المبادرات موثّقة في [`docs/`](./docs/README.md) — لكل مبادرة سرد (STORY) يشرح الدافع، ومواصفة (SPEC) بمعايير القبول.

المبادرة الحالية: **SPEC-003** — الدمج الذكي عند الاستيراد، تحريك العقد، والمحرر المرئي.

## المزايا

- **شجرة بلا حدود عمق** — كل عقدة يمكن أن تحوي عقداً بداخلها، وكل مستوى يأخذ درجة لون مختلفة من لون القسم.
- **بحث ذكي بالعربية** — يطبّع الألف/الياء/التاء المربوطة والتشكيل، ويحوّل النطق العربي إلى المصطلح الإنجليزي (`جافاسكريبت` → `javascript`)، ويتسامح مع الأخطاء الإملائية عبر مسافة ليفنشتاين.
- **بحث صوتي** — ينتقل تلقائياً للنتيجة عند وضوح تفوّقها، وإلا يعرض الخيارات.
- **حفظ تلقائي** في `localStorage` + تصدير/استيراد JSON للنقل بين الأجهزة.
- **استيراد Word** — تتحوّل عناوين Heading 1/2/3 إلى أقسام متداخلة تلقائياً.

## الاختصارات

| الاختصار   | الوظيفة              |
| ---------- | -------------------- |
| `Ctrl + K` | التركيز على البحث    |
| `Ctrl + M` | فتح البحث الصوتي     |
| `↑` `↓`    | التنقل بين النتائج   |
| `Enter`    | فتح النتيجة المحددة  |
| `Esc`      | إغلاق النافذة/البحث  |

## نقل بياناتك من النسخة القديمة

1. افتح `index.html` القديم → زر التصدير ⬇ → «تنزيل نسخة JSON».
2. في نسخة Angular: زر الاستيراد ⬆ → اسحب ملف JSON.
